# Meta Tags and Open Graph Inspector

[![Meta Tags Inspector](https://img.shields.io/badge/TAVARDT-Meta%20Tags-5b3cf5.svg)](https://tools.tavardt.com/au/meta-tags-checker/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Automated HTML metadata evaluation tool for Australian websites, ensuring search snippet optimization and social media card rendering.

Engineered and maintained by the search and digital performance team at **TAVARDT**.

***

## Metadata and Social Card Audit Capabilities

* **Search Snippet Optimization**: Validates character boundaries and pixel width targets for titles and meta descriptions.
* **Open Graph Implementation**: Verifies social parameters (og:title, og:description, og:image, og:url, og:type).
* **Social Network Card Rendering**: Probes Twitter Card formats for visual fidelity across feeds.
* **Crawl and Canonical Verification**: Audits robots meta tags and canonical links to prevent duplicate content indexing.
* **Metadata Quality Score**: Quantitative 0 to 100 rating detailing actionable improvements for organic listings.

***

## Installation and Execution

Requires Python 3.8 or higher with zero external packages.

```bash
git clone https://github.com/TAVARDT-Australia/meta-tags-inspector-au.git
cd meta-tags-inspector-au
python meta_inspector.py example.com.au
```

To run in automated pipelines with JSON output:

```bash
python meta_inspector.py example.com.au -json
```
